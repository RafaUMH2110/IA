# 3. CENTRAL PEDAGOGICAL MESSAGE

Present Prompt Engineering primarily as a **communication and problem-structuring skill**, not as a programming technique.

The central idea should be:

> **A prompt is not simply a question. It is a way of communicating a task, context, objective, constraints, information, and expected result to an AI system.**

Use the following learning methodology throughout the presentation:

**CONCEPT → SIMPLE EXAMPLE → FASHION EXAMPLE → STUDENT QUESTION → IMPROVED EXAMPLE → PRACTICAL APPLICATION**

Whenever possible, demonstrate:

**POOR PROMPT → IMPROVED PROMPT → WELL-STRUCTURED PROMPT**

Always explain what changed and why.

* Identify the target audience.

# 9. SYSTEM PROMPTS VS. USER PROMPTS

Explain visually:

### SYSTEM PROMPT

General instructions defining the AI's role, behaviour, rules, priorities, or constraints.

### USER PROMPT

The specific request or task that the user wants the AI to perform.

Use the analogy:

**SYSTEM = general rules and role**

**USER = specific task**

Keep the explanation conceptual and beginner-friendly.

Do not overwhelm students with API-specific implementation details.
