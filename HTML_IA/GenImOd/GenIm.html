GenIm

Ideas convertidas en fotografías hiperrealistas con Claude y fal.ai

¿Cómo funciona GenIm?

GenIm combina dos inteligencias artificiales distintas, cada una especializada en una tarea.

  1. Escribes las instrucciones del sistema que guiarán a Claude.
  2. Describes tu idea inicial: la prenda o escena que quieres generar.
  3. Claude transforma esa idea en un prompt fotográfico detallado y técnico, en inglés.
  4. Ese prompt se envía automáticamente al modelo de generación de imágenes de fal.ai (FLUX).
  5. La imagen resultante se muestra en la aplicación, lista para descargar.
Tu idea → Claude → Prompt mejorado → fal.ai (FLUX) → Imagen final

Claves de acceso a las API

GenIm se ejecuta enteramente en tu navegador: tus claves solo se usan para llamar directamente a Anthropic y a fal.ai desde este mismo dispositivo, y no se envían a ningún otro servidor.

Obtén tu clave en console.anthropic.com

Obtén tu clave en fal.ai/dashboard

Nota de seguridad: al ser una aplicación de un solo archivo sin servidor propio, las claves se usan directamente desde tu navegador para llamar a las API de Anthropic y fal.ai. No se guardan en ningún almacenamiento permanente, no se incluyen en los archivos descargados (prompts ni imagen) y no aparecen en los mensajes de error. Aun así, evita compartir este archivo ya relleno y no lo publiques en sitios públicos con las claves escritas.
